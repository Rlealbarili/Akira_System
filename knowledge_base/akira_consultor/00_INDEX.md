## Como usar esta base no projeto de IA
- Carregar esta pasta completa no projeto "AKIRA-GEAR".
- Sempre responder decisoes com base nestes documentos antes de sugerir estrategias novas.
- Quando houver lacuna de dado, assumir "nao confirmado" e perguntar apenas o minimo critico.

## Regras de manutencao
- Nao salvar segredos (tokens, senhas, chaves) em documentos.
- Atualizar metas e KPIs mensalmente.
- Registrar mudancas de operacao ou produto em no maximo 24h.
